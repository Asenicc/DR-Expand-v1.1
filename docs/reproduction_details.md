# 复现细节与教师规则

## 主干、数据与预算

未改的作者AGCN `Model_thin`，1116522参数，输入 `[3,64,25,2]`，18类，不增加推理分支或投影头。N源12651条，每轮197次SGD；EA源13568条，每轮212次SGD。各50轮，共20450次学生SGD。教师预训练另需各50轮，共20450次SGD；已有实验复用教师不意味着这部分计算免费。

batch64、drop_last、workers0、FP32，无AMP/TF32。SGD lr0.1、momentum0.9、Nesterov、weight_decay1e-4；zero-based第30/40轮各衰减10倍。Python、NumPy、Torch、CUDA、loader seed均为0；独立CUDA搜索Generator seed为91026。学生随机初始化，不加载教师作为初始化。

原旋转 `my_random_rot(theta=30)` 的角参数范围实际为±60度，不能描述成均匀SO(3)。Recover沿用作者 `ABL_linearextrap_beta`、`cropresize0.7`，48条Recover与16条原样本组成64条混合视图，不是坐标插值。

## 扩展与关系

共同整体尺度0.85–1.15、共同规范Z轴旋转±15度；8组骨长0.9–1.1，参数跨双侧和两人共享。保留帧序与空人物。

10锚点 `[0,2,3,6,7,10,11,15,19,20]` 的组合顺序定义前45条同人距离；后6条为 `[(7,7),(7,11),(11,7),(11,11),(0,0),(3,3)]` 的跨人距离。尺度使用有效躯干20–0长度的平均值。单人无跨人关系；同人距离按当帧有效人物平均。人物/帧有效掩码不等同逐关节质量掩码。

权重只用本源完整训练集一次拟合：每条距离轨迹的均值、总体标准差、绝对一阶差分均值；类对其余类的Fisher式比值，分母加1e-3，各统计先截断到5再平均，要求当前类及其余类各至少2条有效序列。其余类按有效序列合并，不先按17个类别等权平均。加0.25底值后，**每类别在全部51列上归一化到行均值1、行和51**。

平方误差按各关系参考轨迹能量归一化，包含0.25倍时间差分残差；随后按有效通道加权平均，分母 `sum(weights*active).clamp_min(1)`。正式权重的前45列和：N为39.844535–46.563058，EA为23.233362–47.323222；正常有效样本不触发此下限。改为行和1但保留clamp会放松单人约束，不能当作等价重构。全空序列返回0。

前5轮无新增搜索；第6轮起在归一化参数空间随机初始化±0.1，两步符号梯度上升，步长0.5、投影[-1,1]；目标为 `CE - 2*q`。搜索期间骨干eval、参数冻结、BN不更新。优化直接使用平方误差q，避免零残差处 `sqrt(q).square()` 的非有限梯度。

最终检查 `sqrt(q)<=0.08`。按原代码 `range(backtracking_steps+1)`、backtracking_steps=8循环，每次超阈值只将骨长参数减半，必要时将非刚性骨长参数清零；整体旋转/尺度保留。精确循环与仍失败标志行为以未改源码为准，不能擅自简化。

## 损失与教师

`L = 0.5*(CE(z_original,y)+CE(z_expanded,y)) + 0.1*SupCon(T=0.1) + 0.25*KL(T=2)`。

SupCon直接作用于L2归一化256维骨干特征，无新增投影头；同类非自身均为正，其他非自身项均进分母，无本轮以外的跨主体/相机或显式难负例加权。两视图合批128一次骨干forward、一次学生SGD；BN及计算不同于原Recover的64条混合批CE。

- N→E和N→P教师：本源 `RAR_N_seed0/last.pt`，seed0固定第50轮。
- EA→N和EA→P教师：本源 `RAR_EA_seed0/last.pt`，seed0固定第50轮。
- 两源不共享教师，不按目标最高分/最佳种子选择教师，不将老师的权重加载为学生初始化。
- 教师eval并冻结全部参数和BN；只有教师在原旋转源视图上argmax等于源真标签时参与KL，无置信度阈值。
- KL为 `KL(teacher || student_original)`，温度2、乘T²后按正确教师样本数归一化，计数下限1；无正确教师样本则KL=0，系数固定0.25。
- 初始化教师使用 `torch.random.fork_rng(devices=[0])`，保留学生后续RNG。

## 历史结果与后续口径

历史四方向是固定epoch50；不得标成逐轮最佳。新入口默认逐目标最佳BA，保存全部50轮的检查点/目标预测与 `best_by_target.json`；同最高分取最早轮，各目标独立选轮，四方向算术平均。此时用了目标标签选检查点，须披露target-oracle。

逐轮目标评估用fork_rng及NumPy/Python状态恢复，避免验证DataLoader消耗源训练RNG；评估前后检查模型/BN哈希一致。教师仍固定源域epoch50，并不随学生目标选轮改变。

原N源v1在第6轮因 `sqrt(q).square()` 零残差梯度失败，v1.1继承已完整保存的前5轮（此时无新增搜索），恢复模型/SGD/全部RNG后继续。原未提交第6轮更新丢弃；EA随机初始化完整50轮。原路径、协议及校验记录作为历史证据保留，不自动恢复它们。
